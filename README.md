Swiggy Food Delivery Data Analysis

Project Overview

This project focuses on analyzing Swiggy food delivery data using SQL Server. The analysis helps understand restaurant performance, customer orders, food prices, and delivery trends.

Project Objectives

- Analyze total orders and revenue.
- Identify popular restaurants and food items.
- Analyze average food prices.
- Understand customer ordering patterns.
- Evaluate delivery performance.

Tools & Technologies

- SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- Aggregate Functions
- Joins
- Subqueries
- CTEs
- Window Functions
- CASE Statements

Business Questions

1. What is the total number of orders?
2. What is the total revenue?
3. Which restaurants receive the highest number of orders?
4. Which food items are most popular?
5. What is the average order value?
6. Which restaurants generate the highest revenue?
7. What are the order trends?

Key Insights

The project identifies restaurant performance, popular food items, revenue patterns, and customer ordering trends through SQL queries.
